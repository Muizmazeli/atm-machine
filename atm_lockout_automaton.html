Formal Definition — M = (Q, Σ, δ, q0, F)

Q  = { S0, S1, S2, LOCKED, ACCEPT }
Σ  = { C, W }  // C = correct PIN attempt, W = wrong PIN attempt
q0 = S0
F  = { ACCEPT }  // LOCKED is a non-accepting trap state
δ: S0,C→ACCEPT  |  S0,W→S1  |  S1,C→ACCEPT  |  S1,W→S2  |  S2,C→ACCEPT  |  S2,W→LOCKED
Equivalent regular expression: W{0,2} C (C|W)*  — a correct PIN must appear within the first three attempts.
